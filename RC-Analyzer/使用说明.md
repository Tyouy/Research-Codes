# RC analyzer

双击桌面的 **RC analyzer** 图标，或直接运行 `dist/RC analyzer.exe`。Windows 版独立程序，不需要启动 Python 或 Jupyter。首次启动需要等待程序解压。

1. 点击「添加文件」，可以多选 `.dat`、`.txt`、`.csv`。
2. 设置参数，默认值与原 notebook 第一个 cell 相同：Target gate = 5 V；Energy window = 1.84–1.88 eV；Summary gate window = 4–8 V；Colormap = bwr；色标关于 0 对称；保存结果；DPI = 300。
3. 选择最终汇总横轴：文件名 `_xxKREF` 中的温度，或 `TG-BG=xx` 中的电压，也可跳过最终汇总。
4. 选择保存位置并点击「开始分析」。未填写保存目录时，使用首个输入文件所在目录。每次运行创建 `RC analyzer results/时间戳` 子文件夹。
5. 在「图形预览」顶部切换文件及图形；工具栏支持缩放、平移和单张保存。「汇总数据」显示各文件窗口内最大值；「运行日志」显示处理详情。点击「打开结果文件夹」查看导出文件。

取消「保存 PNG 图片和 CSV 数据」后，仍可在界面预览和使用图形工具栏手动保存图片。停止按钮会等待当前操作完成，保留已经完成的结果。

输入格式与原程序一致：第一列为 photon energy（eV），其余列标题为 gate voltage 数值，单元格为 intensity。程序按能量和 gate 升序排列，选取最接近 Target gate 的实际电压。

导出包括各文件的 color map、单 gate 光谱、max−min 曲线及 CSV，全部文件曲线汇总、gate × temperature 矩阵，以及选定横轴的最终汇总 PNG/CSV。矩阵保留原测量值；遇到重复的 gate/temperature 组合会跳过矩阵并在日志提示，不进行平均。最终汇总按横轴数值升序排序。缺少文件名参数或窗口内最大值的文件不会进入最终曲线。

每次运行还保存 `analysis_settings.json`（参数和输入路径）和 `analysis_log.txt`。同名输入文件的导出使用数字后缀区分。

源码：`app.py` 是界面，`analysis.py` 是批处理和绘图，`notebook_core.py` 是从原 notebook 提取的数值函数。原 notebook 保持原样。需要重新构建时，在安装 requirements.txt 的 Windows Python 环境运行 `build.ps1`。
